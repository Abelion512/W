Date: 2026-11-23

`docs/design-review-apple-hig-2026-11-23.md`.
Method: static source audit with the Impeccable detector, manual contrast
computation, and source review. No live browser render was available, so layout

## Findings and actions

### [P1] Popup muted text fails WCAG AA — fixed

- **Location:** `snapgent-extension/popup.html`, `:root` token `--muted-2`.
- **Impact:** version label, pairing label, hints, usage label, and idle dot
  were `#6e6e76` at 3.6:1 on `#16161a` and 3.5:1 on `#161825`, below the
  4.5:1 body-text minimum.
- **Fix:** token raised to `#85858d` (4.93:1 and 4.81:1). All other popup text
  pairs were measured and already pass (body 16:1, muted 6.46:1, error 5.3:1).
- **Guard:** `tests/test_popup_ui.py`.

### [P2] Popup text below the legibility floor — fixed

- **Location:** `popup.html` — `.ver`, `#servers`, `#usage`, `.u-label`,
  `.pair label`, `.hint`, `code`.
- **Impact:** 10–11 px copy is hard to read in a small, high-DPI popup.
- **Fix:** metadata floor is now 11 px, supporting copy 12 px, code 11.5 px;
  body stays 13 px.

### [P2] Emoji used as button icons — fixed

- **Location:** `popup.html` rotate/forget buttons and their reset labels in
  `popup.js`.
- **Impact:** `🔑` / `🗝` render as colour emoji where `font-variant-emoji`
  is unsupported, breaking the monochrome glyph language of the other buttons.
- **Fix:** labels now name the action as text: "Rotate token", "Forget saved
  token". Symbol glyphs `↻ ⟳ ⚙` remain as supplementary decorations.

### [P2] Workflow page heading, list, and selected state — fixed

- **Location:** `docs/snapgent-workflow.html`.
- **Impact:** `<h1>` jumped straight to `<h3>`, so screen-reader outline skipped
  a level; note buttons sat directly inside `<ul>` without `<li>`; the active
  note had no visible or semantic selected state; the canvas had no accessible
  name and the buttons had no explicit focus ring.
- **Fix:** note headings are `<h2>` in both static markup and the injected
  template; each button is wrapped in `<li>`; `aria-pressed` toggles on the
  selected note with a matching border/fill; canvas has `role="img"` and an
  Indonesian `aria-label`; `:focus-visible` uses the accent token.

### [P3] Overlay `max-height` transition — accepted

- **Location:** `overlay.css`, `.zs-chip-body` (`transition: max-height 0.22s`).
- **Reason:** the expandable chip needs a bounded height with internal scroll
  so a large tool output never pushes the composer. `tests/test_overlay_responsive.py`
  locks `max-height`, `vh`, and `overflow-y: auto`. Replacing it with
  `grid-template-rows` would change that containment, not just the animation.

### [P3] Docs nested cards — accepted

- **Location:** `docs/index.html` / `styles.css` (`.band`, `.tool-groups`,
  `.install-steps`, `.fixes`).
- **Reason:** the docs site intentionally uses a neumorphic surface language:
  a raised band containing inset wells containing raised rows. Removing one
  level would replace the committed visual world rather than refine it.
  Contrast in that world passes AA (`--muted` 5.76:1, `--accent` 5.41:1 on
  `#e0e0e0`).

### [P3] Docs `overflow-x: clip` reported as clipping a positioned child — not reproduced

- **Location:** `docs/styles.css`, `body { overflow-x: clip }`; mobile
  `.site-nav` is absolutely positioned inside a sticky header.
- **Reason:** `overflow-x: clip` with default `overflow-y: visible` does not
  create a vertical clip container, and the dropdown spans the header width
  inside the viewport. Flagged by the static detector, not observed in a render.
