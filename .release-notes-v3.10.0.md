## snapgentV3 V3.10.0

This release turns the web AI chats into a proper A2A agent on your own machine, pairs the extension without copying a token, and fixes Grok's composer so Start works there at all.

### Fixed
- **Grok: the prompt now reaches the real editor.** grok.com keeps a hidden 0px mirror `<textarea>` beside its tiptap composer, and the prompt was being typed into the mirror, so Start died with "Grok send button did not become available". The editor is chosen by box size now, a cold-start restore no longer races the tab's first render, and a cold reply gets a 150 s warmup instead of 60 s. `test-grok-editor.js` runs in CI.
- **A blocked session says why.** A refusal from the site itself (for example Grok's "Free tier limit reached") is carried into the A2A error, so you get the site's words in seconds instead of 90 s of waiting and a bare "could not start a session".
- **The in-page bar looks like part of the composer.** Flat and flush on Claude and Gemini instead of a floating card, docked below a centered composer on Grok, and the `⚠ unstable` pill moved so it no longer covers GLM's own chip.
- **Arena starts on a restored Battle page**, where Start previously refused every time while the one-shot restore lost its race with the dropdown.
- **A timed-out prompt no longer locks the tab.** The bridge sends `cancel_prompt`, the extension relays it, and the tab stops the native generation and clears its running state; a 15-minute hard cap covers a lost cancel.
- **Claude reply text is clean** — action-bar glyphs, the "just now" timestamp and screen-reader live regions are excluded.
- **The extension stops redialling the bridge with a missing token** (#28), and edge-anchored overlay surfaces stay inside the viewport instead of hanging off a narrow window (#17, #18).

### Added
- **A2A facade.** `a2a_server.py` exposes the web AI chat as an A2A 1.0 agent on `http://127.0.0.1:17614` — Agent Card, JSON-RPC 2.0, tasks, SSE streaming, bearer token — started and stopped by the bridge in the same process, which prints the URL and token at startup. `metadata.provider` pins a single provider for A/B runs, and the popup shows the last task (model, tier, tokens, duration). See `docs/a2a.md` and `.snapgent/skills/a2a-bridge/SKILL.md`.
- **Token-free pairing.** The bridge accepts the extension on the Origin allowlist alone, so the popup connects on its own; a web page still cannot reach the bridge, and a client sending no `Origin` still needs `~/.snapgent/bridge_token`. The old rule remains as `ZS_BRIDGE_AUTH=strict`.
- **The A2A token persists** in `~/.snapgent/a2a_token` (mode 600) instead of only being printed.
- **Hardened tools.** Symlink traversal out of the workspace is refused, `run_command` gained a timeout (5–300 s, default 30) and a deny list for privilege-escalation and raw-disk binaries, and the bridge auto-recovery now backs off 5 s → 300 s.
- **`get_bridge_status`**, opt-in JSON bridge logs (`ZS_BRIDGE_LOG_JSON=1`) and a popup view of per-server pid / RSS / uptime / retry countdown.
- **Docs:** `docs/security-and-ops.md`, `docs/code-standards.md` (with `.editorconfig`, `pyproject.toml`, pyflakes and `node --check` in CI), and a live provider matrix in `docs/model-routing.md` — seven of twelve text providers verified end to end, Grok included after its quota reset (`PASS grok 93.4s` cold, `4.4s` warm, `STABLE`).

### Changed
- **One design scale.** Radius, spacing, type and the 32px control height are now steps of a single token set, so seating a new provider cannot drift into 7px here and 9px there; off-grid values moved to the nearest step and nothing shifted by more than 1px.
- **Dependencies are tracked and current.** Dependabot watches pip, npm and GitHub Actions; merged since the last release: `websockets` 17.4, `pytest` ≥9.2, `pyflakes` ≥4.1, `electron` 45, the `actions` group and the npm-and-yarn group.
- Extension version bumped to **3.10.0**. Reload the extension so the popup shows `ext v3.10.0`.
- The release badge, install link and footer in `README.md` now point to V3.10.0.

### Upgrade
Pull the latest `main`, reload the extension at `chrome://extensions` (or `edge://extensions`) and refresh open chat tabs (F5). This release changes bridge code (A2A facade, handshake auth, hardened tools), so restart the bridge from the new tree — and rebuild `bridge.exe` if you run the prebuilt binary. The bridge now reports 3.10.0 in step with the extension (the Snapgent App stays 0.1.1), so the popup no longer flags a version difference.
